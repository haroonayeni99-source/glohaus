# Homepage and category image controls

Owner path: `/admin#homepage-media` → **Homepage and category images**.

- Homepage photos: upload a desktop or mobile hero, preview, enter a reason and select **Save homepage images**.
- Category photos: select **Desktop homepage** or **Mobile homepage**, upload a JPEG/PNG/WebP up to 3 MB (or supply an HTTPS image URL), inspect the circular crop, then select **Save category images**.
- **Use default for [category]** restores just that category after saving. Category names, search links and ordering stay the same.
- Mobile category defaults and layout are preserved. Desktop and mobile hero photos are also independent; a desktop hero update no longer replaces an unset mobile hero.
- Uploads remain private until saved. Publishing requires the existing verified Owner access and adds an audit entry. Hero and category settings are stored independently.
