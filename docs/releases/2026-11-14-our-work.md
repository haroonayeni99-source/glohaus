# Our Work — Concept C

Production target: haroon-glohaus/glohaus1 only. Owner implementation, merge and production authorisation received 14 November 2026.

## Scope

The existing public professional profile receives a three-column 9:16 work grid. Uploaded published photos/videos and published social posts use one surface, with treatment collections derived from existing speciality assignments. Existing featured social work sorts first and displays a pinned indicator. No new pin, collection, database or publication permissions are introduced.

Tiles never autoplay. Images load lazily; uploaded video cover metadata loads near the viewport. The native full-screen dialog has vertical swipe navigation, previous/next controls, Escape, browser Back, focus restoration, body-scroll cleanup and safe-area padding. Only the selected uploaded video is mounted in the viewer; it starts muted with normal play and sound controls. Existing social player consent and original-post recovery remain intact. No invented view/engagement metrics are shown. Book this look appears only for a linked named service and points to the existing service booking route.

Discover retains its existing SocialPortfolio/DiscoverPortfolio rendering. Uploads, import/sync controls, private drafts and publication repositories are unchanged. Existing profile examples retain their current presentation.

## Verification

The focused browser job covers both themes at 390/1440 pixels: tile ratio/columns, collections, exclusion of draft posts, featured ordering, conditional service link, single viewer video, muted default/sound toggle, Escape/Back, focus and scroll restoration, zero document overflow and no provider request before explicit consent. Fictional media failures are intentional in the fixture. Full repository CI and Vercel Preview are required before production merge.

## Limits and rollback

Collections are existing treatment groups; creating named custom collections and pinning uploaded work would need a separate data model. Physical iPhone/Android checks and signed-in live-provider testing are not represented by browser fixtures. Public provider activation remains disabled.

Rollback: revert this source commit or restore the preceding glohaus1 production deployment. No data migration or financial operation is part of this change.
